# STRIDE Threat Model - AI/Gemini Integration (OWASP LLM Top 10)

| Threat Category | Description | Specific Impact on NetSentinel | Mitigation |
|---|---|---|---|
| **Spoofing** | Prompt injection via captured network data (HTTP headers, DNS names, payloads) sent to Gemini for analysis. | LLM treats attacker-controlled text as instructions, potentially triggering unauthorized actions. | `Guardrail::detect_prompt_injection()` in `netsentinel-core::ai` blocks 9 known patterns (EN/FR). System prompt explicitly forbids treating captured data as instructions. No LLM output directly triggers privileged actions — all go through PDDL validation first. |
| **Tampering** | LLM returns fabricated vulnerability severity or false PQC compliance status. | Incorrect security assessments in reports; false sense of safety or unnecessary panic. | All LLM-generated conclusions in reports are labeled "Genere par IA — a verifier" (LLM09). Findings are cross-referenced against the signed vulnerability database (`vuln_database.json` SHA-256 verified) and NIST PQC reference (`pqc_nist_reference.json`). Gemini responses logged to audit ledger with confidence level. |
| **Repudiation** | Operator claims an AI-suggested remediation was not reviewed before execution. | Dispute over responsibility for damaging automated action. | Every AI decision (L1/L2) is immutably logged in the audit ledger with: timestamp, agent ID, model version, input/output (PII-redacted), PDDL validation result. Human confirmation required for all irreversible actions. |
| **Information Disclosure** | Sensitive data (captured credentials, internal IPs, network topology) sent to external Gemini API. | Confidential client data exfiltrated to Google cloud. | `Guardrail::strip_pii()` redacts IPv4, emails, MAC addresses before any API call. Only aggregated vulnerability summaries are sent, never raw packet data or credentials. API key stored exclusively in GNOME Keyring (`netsentinel-core::secrets::KeyringStore`). User must explicitly opt-in to cloud AI in Settings (§5.H). |
| **Denial of Service** | Unbounded API calls to Gemini (LLM10) consuming quota/budget, or AI agent triggering infinite scan loops. | Financial loss from API overuse; local network DoS from AI-driven scans. | Rate limiting and daily budget cap configurable in Settings. PDDL rate-limit rule blocks agent loops. `GeminiClient` has timeout on HTTP requests. Offline fallback summary when API is unavailable or budget exhausted. |
| **Elevation of Privilege** | Malicious LLM output (injected or hallucinated) proposes a command that, if rendered in UI without escaping, could be interpreted as markup or a shell command. | Pango markup injection in GTK4 UI; or social engineering user into executing dangerous commands. | All LLM output is Pango-escaped before rendering. `Guardrail::sanitize_commands()` blocks `rm -rf`, `mkfs`, `dd`, `chmod 777` patterns. No `eval()` or `exec()` on LLM output anywhere in codebase. Proposed remediations are translated to formal PDDL goals, not executed as shell commands. |
